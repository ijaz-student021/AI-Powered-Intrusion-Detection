Model Training

These models were trained on the UNSW-NB15 dataset using an 80/20 train/test split. Due to severe class imbalance, SMOTENC (Synthetic Minority Over-sampling Technique for Nominal and Continuous) was applied to the training set. A RobustScaler was used to handle outliers in the numerical features before passing them to the final estimators.

LightGBM · Gradient Boosting

A fast, distributed, high-performance gradient boosting framework based on decision tree algorithms.

MLP · Neural Network

A Multi-Layer Perceptron trained with backpropagation, designed to capture complex non-linear relationships in network traffic.
